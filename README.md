# 竹溪放排 · 竹乡展馆互动小游戏

一个以“看水、过弯、避礁、识滩”为核心的放竹排模拟展项。包含河道地图、竹排编组、放排操作和码头结算四个页面；河道、地形、礁石、树木、竹排与水花均使用 WebGL2 程序化绘制，不依赖外部图片素材。

## 运行

```bash
npm install
npm run dev
```

展馆部署可使用：

```bash
npm run build
npm run preview
```

建议使用新版 Edge / Chrome，并开启硬件加速。桌面端可获得最佳的三十节长排视野；手机端支持触摸撑篙和按住推排。

## 操作

- 鼠标 / 手指在河道上选择篙点。
- 按住左键、手指或 `Space` 蓄力，松开后竹篙撑到河底借力。
- `A` / `D` 或 `←` / `→` 调整键盘篙点的左右位置。
- 按住 `E` 或“下水推排”：浅滩搁浅时人力推回深槽，撞石卡住时也可顶开。
- `P` / `Esc`：暂停。

## 已实现的策划规则

- 河道由控制点和 Catmull-Rom 采样生成，包含河宽、曲率、水深、浅滩与礁石。
- 弯道曲率参与流速计算：凹岸/外侧冲刷更深、流速更快，凸岸/内侧水浅流缓。
- 礁石下游生成反向纵向流和横向涡动，表现“回水”。
- 三十节竹排由纵向硬约束、藤条短连接和抗弯距离约束组成；每道藤条实时计算弯折角和应力。
- 弯折角超过编组选择的藤条允许角度时，对应那一道藤条立即断开，前后排可分离。
- 撑篙蓄力越满，排头获得的冲量和转向力矩越大；猛撑会快速推高藤条应力。
- 礁石碰撞按线段最近点求解：碰撞节会被摩擦和卡阻减速，后续节在连接约束下挤压、弯折。
- 每节根据吃水深度与当前水深判断擦浅/搁浅；当 `draft > depth` 时产生强阻力。
- 天气影响流速倍率和水位：春日平水、云雾梅雨、暴雨涨水、连日枯水。
- 三条自编山溪：翠竹溪、九曲回溪、龙吟峡，难度和礁石/浅滩布局不同。
- 码头按实际运到的排节计算毛竹数量，按各节耐久计算完好竹子，并结算货物、用时、断藤、撞石和搁浅。

## 性能

- 河道为静态索引网格；礁石/树木和竹排使用 Instanced Draw；水花使用 `POINTS`。
- 三十节竹排的物理为定步长 TypeScript 约束求解。Node 基线约 **1.8–2.7 ms/帧**。
- HUD 内置实时 FPS；渲染器会在低帧率设备上逐步降低渲染缩放，优先保证交互帧率。
- 硬件 GPU 的无头 Chrome 冒烟测试中，完整页面流程无控制台错误，rAF 约 **144 FPS**；SwiftShader 软件渲染仅用于兼容性冒烟，不代表展馆 GPU 性能。

## 检查

```bash
npm run check:sim
npm run build
```

`check:sim` 会验证外弯流速大于内弯、枯水重载的搁浅条件、超角度猛撑会断藤、各溪水流推进以及三十节物理帧预算。

`scripts/browser-check.mjs` 和 `scripts/mobile-shot.mjs` 是本机浏览器/Puppeteer 冒烟脚本，需要本机安装 Chrome；不属于应用运行时依赖。
