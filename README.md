# 山溪放排 · 竹乡展馆小游戏

给游客玩的放竹排模拟：把砍下的毛竹扎成排，顺着山溪放到下游码头换工钱。
老排工说放排难在看水——急流、回水、浅滩；一排竹子几十米长，前头拐过去了，后头还在弯里。

## 运行

```bash
npm install
npm run build     # tsc 编译到 dist/
npm run serve     # http://localhost:8080
```

打开 `http://localhost:8080` 即可。展馆待机演示模式：`http://localhost:8080/?demo`
（可选 `?demo=xiangshui` / `?demo=luoyan` 指定河道；`&freeze=秒数` 用于调试快进）。

## 四个页面

1. **河道地图页**：三条虚构山溪（青竹溪 / 响水峡 / 落雁滩），标注礁石、浅滩数量与天气预报。
2. **竹排编组页**：选排节数（10–30）、每节竹筒数（影响吃水）、藤条新老（影响允许弯折角与劳损上限）。
3. **放排操作页**：WebGL2 渲染河道与竹排。按住排头附近的水面下篙，篙点在河底借力撑排；
   撑得太猛会累坏排头几节的藤条；滚轮缩放。HUD 显示天气、速度、水深/吃水、藤条状态、篙力表。
4. **码头结算页**：按运到的竹子节数与完好程度结算工钱，老排工给一句点评。

## 玩法规则（对应老人家的说法）

- **看水**：流速/水深按河道地形逐格计算——弯道外侧水急内侧水缓（曲率 × 横向位置），
  石头后面有回水和旋涡，浅滩水浅流急。
- **竹排**：一节节用藤条连着，节间能弯一点。弯折超过藤条允许范围会累积劳损，超限即断；
  一下折死（超过断裂角）当场崩开。
- **排头撑篙**：篙长有限，水太深够不到底；可以点在露出水面的礁石上。撑力超过安全值会伤藤条。
- **卡石**：撞上礁石的那一节会被卡住，后面的跟着挤上来（缠排）。涨水能浮起来，颠簸久了也能挣脱。
- **搁浅**：吃水 > 当地水深就搁浅，摩擦大增，等下雨涨水或用篙硬撑。
- **天气**：途中会变天，下雨涨水——流速变快、水深抬高，搁浅能解，但水急更容易撞。

## 技术

- **TypeScript**：水流场、竹排连接、篙借力、天气、结算全部在 `src/` 的纯计算模块里
  （`flowfield.ts` / `raft.ts` / `pole.ts` / `weather.ts` / `game.ts`），不依赖 DOM，可在 Node 无头跑。
- **WebGL2**（`src/render.ts`）：河道条带网格 + 流场纹理（流向/流速/水深入纹理），
  程序化水纹、急流白浪、石边水花；竹排节/礁石/篙/码头实例化绘制；屏幕空间雨效。
- **竹排物理**：位置动力学（PBD），关节端点重合约束 + 弯折限位 + 岸线/礁石碰撞，
  断裂判定在约束钳制**之前**测量（钳制后就量不到超限了）。

## 测试

```bash
npm run test:sim
```

无头仿真验证：弯道外侧流速 > 内侧、石后回水、搁浅判定（吃水 > 水深）、超限断藤、
30 节排 60 帧性能（实测每步物理约 0.1–0.3ms，帧预算 16.6ms 的零头）、
自动撑篙整趟到港结算。
